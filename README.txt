INTERVALTIMER PER SAFARI

Contenuto:
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js
- icon.svg

IMPORTANTE
Per installarla dalla schermata Home e usarla offline, pubblica tutti i file su uno spazio web HTTPS mantenendoli nella stessa cartella. Apri poi index.html da Safari su iPhone, premi Condividi e scegli Aggiungi alla schermata Home.

PROVA LOCALE SU COMPUTER
Dalla cartella avvia: python3 -m http.server 8080
Poi apri http://localhost:8080

DATI
Gli allenamenti personalizzati sono salvati nel localStorage del browser sul dispositivo.
